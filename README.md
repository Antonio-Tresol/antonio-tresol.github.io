# antonio-tresol.github.io

Personal site for Antonio Badilla-Olivas. Single page; bio, selected work,
and links. Deploys to https://antonio-tresol.github.io/ via the included
GitHub Actions workflow.

## Stack

- Vite + React 19
- Inter (display), Source Serif 4 (body), JetBrains Mono (mono)
- Design tokens shared with the gemma3-refusal-axis explainer site

## Local

```sh
npm install
npm run dev
```

Opens on http://localhost:4003.
